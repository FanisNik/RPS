# Rock, Paper, Scissors 

This is a simple implementation of the classic Rock, Paper, Scissors game using JavaScript. It's a console based project where the user plays against the computer.

## About

- Functions and parameters
- Conditionals
- Random number generation
- User input handling
- Basic game logic

## Features

- Accepts user input (case insensitive)
- Generates a random computer choice
- Determines the winner based on traditional rules:
  - Rock beats Scissors
  - Scissors beats Paper
  - Paper beats Rock
- Logs results to the console

## How to Run

You can run this in any JavaScript environment, such as Node.js or your browser console.
